DESCRIPCIÓN:
Se agregó un DHCP Option Set configurado con los servidores DNS de las dos
instancias EC2 (Ubuntu y Windows) y se asoció a la VPC.

================================================================================
SECCIÓN 1: NUEVA SECCIÓN "Conditions"
================================================================================

UBICACIÓN: Línea 67 (después de Parameters, antes de Resources)

CÓDIGO AÑADIDO:
--------------
Conditions:
    IsUSEast1: !Equals [!Ref 'AWS::Region', 'us-east-1']

PROPÓSITO:
- Define una condición que se usa para determinar el nombre de dominio correcto
- AWS trata us-east-1 como caso especial (usa ec2.internal)
- Otras regiones usan {REGION}.compute.internal

IMPACTO:
- Permite configurar CloudFormation para diferentes regiones AWS
- No afecta recursos existentes

================================================================================
SECCIÓN 2: NUEVO RECURSO "DHCPOptionSet"
================================================================================

UBICACIÓN: Línea 162 (después de AsociacionSubred2, antes de UBUNTU SERVER)

CÓDIGO AÑADIDO:
--------------
DHCPOptionSet:
    Type: AWS::EC2::DHCPOptions
    Properties:
        DomainName: !If
            - IsUSEast1
            - ec2.internal
            - !Sub '${AWS::Region}.compute.internal'
        DomainNameServers:
            - !Sub '10.${RedBase}.1${NN}.100'
            - !Sub '10.${RedBase}.2${NN}.100'
        Tags:
            - Key: Name
              Value: !Sub '${Proyecto}${NN}-dhcp-opts'

PROPIEDADES:
- Type: AWS::EC2::DHCPOptions (creador de DHCP Option Set)
- DomainName: Nombre de dominio dinámico (us-east-1 → ec2.internal)
- DomainNameServers: Array con 2 IPs privadas de las instancias EC2
  * Primaria: Ubuntu Server en SubredPublica1 (10.{RedBase}.1{NN}.100)
  * Secundaria: Windows Server en SubredPublica2 (10.{RedBase}.2{NN}.100)
- Tags: Etiqueta para identificar fácilmente el recurso

BENEFICIOS:
- Configuración dinámica basada en parámetros de entrada
- Fácil de reutilizar con diferentes valores de RedBase y NN
- Resiliencia: 2 servidores DNS

================================================================================
SECCIÓN 3: NUEVO RECURSO "DHCPOptionsAssociation"
================================================================================

UBICACIÓN: Línea 177 (justo después de DHCPOptionSet)

CÓDIGO AÑADIDO:
--------------
DHCPOptionsAssociation:
    Type: AWS::EC2::VPCDHCPOptionsAssociation
    Properties:
        VpcId: !Ref VPC
        DhcpOptionsId: !Ref DHCPOptionSet

PROPÓSITO:
- Asocia el DHCP Option Set a la VPC
- Sin esta asociación, el DHCP Option Set no sería utilizado

EFECTOS:
- Todas las instancias EC2 en la VPC usarán estos DNS
- Instancias lanzadas después reciben automáticamente esta configuración
- Instancias lanzadas antes pueden necesitar renovar DHCP
